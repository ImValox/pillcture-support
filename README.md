# PillCture — Support

Pour toute question, bug ou suggestion concernant l'app PillCture :

📧 **Contact** : ton.email@gmail.com

## Questions fréquentes

**L'alarme ne se déclenche pas**
Vérifie que les notifications sont autorisées dans Réglages > PillCture > Notifications.

**La caméra ne s'ouvre pas**
Vérifie que l'accès caméra est autorisé dans Réglages > PillCture > Caméra.

**Réinitialiser mes données**
Va dans l'onglet Paramètres > Réinitialiser.
