Questions fréquentes

L'alarme ne se déclenche pas

Vérifie que les notifications sont activées : Réglages → PillCture → Notifications → Autoriser les notifications.

La caméra ne fonctionne pas

Vérifie les autorisations : Réglages → PillCture → Caméra.

Mes données sont-elles partagées ?

Non. Toutes les données restent uniquement sur ton appareil. Aucune donnée n'est envoyée à un serveur.

Comment réinitialiser l'app ?

Onglet Paramètres → Réinitialiser les données.
